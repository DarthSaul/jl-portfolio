# jl-portfolio

Portfolio and photography showcase website. Built with Next.js and Sanity.

- `web/` — the Next.js app (Vercel's root directory)
- `studio/` — the Sanity Studio, deployed separately to `joanatstake.sanity.studio`

See [CLAUDE.md](./CLAUDE.md) for the project charter and [DESIGN.md](./DESIGN.md) for the
design spec.
